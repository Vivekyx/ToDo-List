# To-Do List – GUI Based Application

This is a GUI-based To-Do List project that I developed using Python and Tkinter. It helps users manage their daily tasks through a simple graphical interface.

# Features

- Add new tasks
- View added tasks
- Update existing tasks
- Delete tasks
- Automatically save tasks
- Store task data in a JSON file

# Technologies Used

- Python
- Tkinter
- JSON

# What I Learned
 
- Creating GUI-based applications using Tkinter.
- Working with buttons, labels, entry fields and listboxes.
- Performing add, update and delete operations.
- Saving and loading data using JSON.
